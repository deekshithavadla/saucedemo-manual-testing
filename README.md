# SauceDemo Manual Testing Project

## Project Overview

This is a self-learning manual testing project based on the SauceDemo demo e-commerce website. The project focuses on testing key application features, preparing test cases, and documenting test results and observations.

## Application Under Test

- **Website:** https://www.saucedemo.com/
- **Testing Type:** Manual Testing
- **Domain:** E-commerce
- **Tools Used:** Web browser, Microsoft Excel, Microsoft Word, Claude (AI-assisted test scenario exploration)

## Features Tested

- Login functionality
- Invalid login credentials
- Product sorting
- Add-to-cart functionality
- Remove-from-cart functionality
- Checkout process
- Logout functionality
- Product image behavior using the `problem_user` account

## Project Files

| File | Description |
|---|---|
| `01_Manual_Exploratory_Testing.docx` | Manual exploratory testing notes |
| `02_AI_Exploratory_Testing_Claude.docx` | AI-assisted test scenario exploration and validation |
| `03_Test_Cases.xlsx` | Test cases with expected and actual results |
| `04_Bug_Reports.xlsx` | Documented observations and investigation records |
| `05_Test_Summary_Report.docx` | Overall testing summary and learning outcomes |

## Testing Approach

1. Explored the application manually.
2. Tested positive and negative login scenarios.
3. Checked product sorting and cart functionality.
4. Tested checkout and logout flows.
5. Recorded expected results and actual observations.
6. Documented findings and areas requiring further verification.

## Key Observations

- The `problem_user` account displayed the same dog image across multiple products.
- Checkout validation behavior required further verification.
- The observations were documented without treating unconfirmed issues as verified defects.

## Skills Practiced

- Manual Testing
- Test Case Design
- Exploratory Testing
- Positive and Negative Testing
- Expected vs. Actual Result Analysis
- Test Documentation and Reporting
- Basic AI-assisted Test Scenario Exploration

## Limitations

This project covers selected manual testing scenarios only. Automation, performance, security, and comprehensive cross-browser testing were not performed.

## Disclaimer

SauceDemo is a demo application used for learning and practice. This repository represents a self-learning testing project, not professional client work.
